## Summary

Integrated the DevTools module into the NovaBrowser networking layer. The module provides three panels — Console (leveled logging, printf formatting, duplicate collapsing, grouping), Network Monitor (Resource-Timing-style phases, firewall decision tracking, HAR export), and DOM Inspector (tree walking, CSS selector-lite query engine, selection, breadcrumbs, box-model/style adapters) — wired together by a composite `DevTools` facade.

## File Placement

Placed at `src/browser/netwroking/devtools.ts` — same directory as its dependencies (`ip-protocol.ts`, `firewall.ts`) since it uses relative imports.

## Architecture

```
DevTools (facade)
 ├── ConsoleService         — leveled logging, duplicate collapsing, global console patching
 ├── NetworkMonitor         — per-connection entries, timing phases, firewall decisions, HAR export
 └── DOMInspector           — tree walking, CSS selector-lite, selection, breadcrumbs
```

## Key Interfaces

- `DOMNodeLike` — minimal DOM contract (nodeId, tagName, attributes, children, textContent)
- `StyleProvider` / `BoxModelProvider` — adapter functions for engine-specific data
- `ConsoleFilter` — level + query filtering
- `NetworkEntry` — Resource-Timing-style with optional HTTP metadata slots
- `CompoundSelector` — parsed CSS selector-lite (tag/#id/.class/[attr]/[attr=value])

## Code Quality
