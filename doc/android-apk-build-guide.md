# Nova Browser — Android APK Build Guide

**Date:** 2026-07-22
**Status:** Ready (requires Android SDK installation)

---

## Prerequisites

You need to install these tools on your Windows machine:

### 1. Java JDK 17+
```powershell
# Download from https://adoptium.net/temurin/releases/?version=17
# Or install via winget:
winget install EclipseAdoptium.Temurin.17.JDK
```

### 2. Android Studio (includes SDK)
```powershell
# Download from https://developer.android.com/studio
# Install with default settings
# During setup, make sure to install:
#   - Android SDK Platform 34
#   - Android SDK Build-Tools 34
#   - Android SDK Command-line Tools
```

### 3. Set Environment Variables
```powershell
# Add to your system PATH:
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
$env:PATH += ";$env:JAVA_HOME\bin;$env:ANDROID_HOME\platform-tools;$env:ANDROID_HOME\tools"
```

## Build Steps

### Step 1: Build the Web App
```powershell
cd E:\nova_1
npm run build:web
```

### Step 2: Initialize Capacitor Android
```powershell
npx cap add android
```

### Step 3: Sync Web Assets to Android
```powershell
npx cap sync android
```

### Step 4: Build the APK

**Option A: Debug APK (no signing required)**
```powershell
cd android
.\gradlew assembleDebug
```
Output: `android/app/build/outputs/apk/debug/app-debug.apk`

**Option B: Release APK (requires signing)**
```powershell
cd android
.\gradlew assembleRelease
```

### Step 5: Install on Device
```powershell
# Connect Android device via USB (enable USB debugging)
adb install android/app/build/outputs/apk/debug/app-debug.apk

# Or copy the APK to your phone and install manually
```

## Customization

### Change App Icon
Place your icon at `android/app/src/main/res/` in the appropriate mipmap folders:
- `mipmap-mdpi` (48x48)
- `mipmap-hdpi` (72x72)
- `mipmap-xhdpi` (96x96)
- `mipmap-xxhdpi` (144x144)
- `mipmap-xxxhdpi` (192x192)

### Change App Name
Edit `android/app/src/main/res/values/strings.xml`:
```xml
<resources>
    <string name="app_name">Nova Browser</string>
</resources>
```

### Change Package Name
Edit `capacitor.config.ts`:
```typescript
appId: 'com.yourcompany.novabrowser',
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| `JAVA_HOME not set` | Install JDK and set JAVA_HOME environment variable |
| `Android SDK not found` | Install Android Studio and set ANDROID_HOME |
| `gradlew not found` | Run `npx cap add android` first |
| `Build failed` | Check Java version (need 17+), check SDK versions |
| APK too large | Run `npx cap sync --prod` before building |
